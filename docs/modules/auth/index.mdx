ContiNew Starter 认证模块（`continew-starter-auth`）提供三类按需独立引入的认证能力：

- **Sa-Token**（`continew-starter-auth-satoken`）：Sa-Token 框架的扩展集成，提供样板化配置、登录拦截器与可切换的持久层实现；
- **JustAuth**（`continew-starter-auth-justauth`）：JustAuth 第三方登录的默认处理，内置 Redis State 缓存与自定义平台扩展机制；
- **Refresh Token**（`continew-starter-auth-refresh-token`）：可轮换 Refresh Token 登录会话，为前后端分离系统提供「短期 Access Token + 长期 Refresh Token」双令牌体系。

## 核心依赖

| 依赖 | 描述 |
|:-----|:-----|
| `top.continew.starter:continew-starter-cache-redisson`（optional） | 缓存模块 - Redisson（Sa-Token Redis 持久层、JustAuth Redis State 缓存、Refresh Session 存储的共同基础） |
| `top.continew.starter:continew-starter-messaging-websocket` | 消息模块 - WebSocket（Refresh Token 模块：登录会话撤销后实时关闭对应连接） |
| `cn.dev33:sa-token-spring-boot3-starter` | Sa-Token（轻量级 Java 权限认证框架） |
| `cn.dev33:sa-token-jwt` | Sa-Token 整合 JWT（`sid` 会话声明的前置条件） |
| `cn.dev33:sa-token-redisson` | Sa-Token 集成 Redisson 客户端 |
| `me.zhyd.oauth:JustAuth` | JustAuth（整合第三方登录的开源组件） |
| `com.xkcoding.justauth:justauth-spring-boot-starter` | JustAuth Spring Boot 集成 |
