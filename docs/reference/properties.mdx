本页汇总 ContiNew Starter 各模块的自动配置项，所有配置项名、默认值均与源码中的 `*Properties` 类（`@ConfigurationProperties`）逐一核对。

<Callout type="info">
阅读说明：

- 「—」表示源码中未设置默认值（即 `null` / 空集合，由底层框架自行兜底）；
- 部分配置项直接扩展自 Spring Boot 或第三方框架的命名空间（如 `application`、`spring.task`、`spring.data.redisson`、`spring.jackson`、`mybatis-plus.extension`、`mybatis-flex.extension`、`server.extension`、`sa-token.extension`），可与框架原生配置混写；
- 各模块的完整用法说明见 [功能模块](/docs/starter/modules) 下的对应页面。
</Callout>
