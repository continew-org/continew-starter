description: 说明 ContiNew Starter 如何通过 BOM 统一管理第三方依赖与各功能模块的版本，以及如何查看锁定版本、按需覆盖版本。
---

ContiNew Starter 通过两个 POM 模块统一供给版本：

- `continew-starter-dependencies`（第三方依赖 BOM）：集中锁定 Spring Boot、Spring Cloud 及全部第三方库版本，并导入 `continew-starter-bom`；
- `continew-starter-bom`（模块 BOM）：统一管理全部 `continew-starter-*` 功能模块的版本。

引入依赖管理后，使用任何 ContiNew Starter 模块或被锁定的第三方库时均**无需指定版本号**，从根本上避免版本冲突与版本漂移。

## 引入依赖

在 `pom.xml` 的 `dependencyManagement` 中以 `import` 方式导入（也可改用 parent 方式，见[快速开始](/docs/starter)）：

```xml
<dependencyManagement>
    <dependencies>
        <!-- ContiNew Starter Dependencies -->
        <dependency>
            <groupId>top.continew.starter</groupId>
            <artifactId>continew-starter-dependencies</artifactId>
            <version>${continew-starter.version}</version>
            <type>pom</type>
            <scope>import</scope>
        </dependency>
    </dependencies>
</dependencyManagement>
```

引入后即可直接使用，版本由 BOM 统一供给：

```xml
<dependencies>
    <!-- Web 模块 -->
    <dependency>
        <groupId>top.continew.starter</groupId>
        <artifactId>continew-starter-web</artifactId>
    </dependency>

    <!-- Redisson（不仅仅是一个 Redis Java 客户端） -->
    <dependency>
        <groupId>org.redisson</groupId>
        <artifactId>redisson-spring-boot-starter</artifactId>
    </dependency>
</dependencies>
```

<Callout type="info">
`${continew-starter.version}` 请替换为最新版本号，可在 [Maven Central](https://central.sonatype.com/search?namespace=top.continew.starter) 查询。
</Callout>

## 自定义依赖版本

原则上不建议修改 ContiNew Starter 锁定的依赖版本，集中管理的意义就在于保证各组件兼容性。但如有特殊需求（如紧急修复漏洞、对齐公司统一版本），可通过以下方式覆盖。

<Callout type="warn">
覆盖版本可能引入兼容性问题，调整后请充分测试；覆盖用的属性名必须与 `continew-starter-dependencies` 中定义的完全一致。
</Callout>

### 方式一：覆盖 properties（parent 引入时推荐）

以 `parent` 方式引入 ContiNew Starter 时：

```xml
<parent>
    <groupId>top.continew.starter</groupId>
    <artifactId>continew-starter</artifactId>
    <version>${continew-starter.version}</version>
</parent>
```

可利用 Maven 继承特性，在项目 `pom.xml` 的 `properties` 中覆盖同名版本属性。例如将 Spring Boot 调整为 `3.4.7`：

```xml
<properties>
    <!-- 覆盖 Spring Boot 版本 -->
    <spring-boot.version>3.4.7</spring-boot.version>
</properties>
```

### 方式二：通过 dependencyManagement 声明

基于 Maven 依赖解析原则（路径最近者优先、第一声明者优先），可直接在项目 `pom.xml` 的 `dependencyManagement` 中声明目标版本，且声明位置需**先于** `continew-starter-dependencies` 的导入：

```xml
<dependencyManagement>
    <dependencies>
        <!-- 先声明要覆盖的依赖版本 -->
        <dependency>
            <groupId>cn.hutool</groupId>
            <artifactId>hutool-all</artifactId>
            <version>5.8.40</version>
        </dependency>
        <!-- 再导入 ContiNew Starter Dependencies -->
        <dependency>
            <groupId>top.continew.starter</groupId>
            <artifactId>continew-starter-dependencies</artifactId>
            <version>${continew-starter.version}</version>
            <type>pom</type>
            <scope>import</scope>
        </dependency>
    </dependencies>
</dependencyManagement>
```
